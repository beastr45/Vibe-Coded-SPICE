# Building the Tauri GUI

The Tauri application in `apps/spice-studio` deliberately borrows the workflow shape of LTspice. The left panel is a component palette, the center is a dark schematic canvas, the right panel edits the selected symbol, the lower-left area exposes the generated netlist, and the lower-right area becomes the waveform or report pane after a simulation is run.

The frontend is written in React and TypeScript because that makes rapid UI iteration straightforward while keeping the desktop shell lightweight. Tauri commands in `apps/spice-studio/src-tauri/src/main.rs` handle simulation and project export. The command `run_simulation` passes a netlist string to `spice-core`, and `save_project_bundle` writes three artifacts: the SPICE netlist, the SVG schematic, and a small JSON manifest that ties them together.

The UI implementation in `apps/spice-studio/src/App.tsx` is intentionally modest rather than over-engineered. It demonstrates the essential loop: construct or edit a schematic, derive a netlist, run the solver, display the result, and export a durable project bundle. The current version now derives that netlist primarily from schematic geometry: wire endpoints are merged into inferred nets, wire labels become preferred names for those nets, and the per-symbol fallback node fields remain available only when a pin is still unwired. From here you can add wire snapping, symbol libraries, drag handles, ERC, library browsers, and still richer inference rules.

In the current phase, the GUI now goes a step further: the canvas supports click-to-place editing on a fixed grid, two-click wire creation, movement nudging for selected symbols, controlled-source placement, inferred nets from drawn connectivity, and lightweight inline waveform plots for both transient and AC analyses. It is still not a full LTspice clone, but it now behaves much more like a real interactive schematic workbench rather than just a static shell.

The latest iteration also improves the day-to-day schematic loop. Wires now have editable visible net labels, source components can be filled from quick stimulus templates such as `DC`, `SIN`, and `PULSE`, plotted traces can be toggled on and off in the results pane, and clicking a chart drops measurement cursors that report the selected x-positions together with each active trace value. A normal click places cursor A, while a shift-click places cursor B so the pane can report simple derived metrics such as `Δx`, `1/Δx`, per-trace `Δy`, a secant-like slope over the cursor interval, and the average sampled value between the cursors. Those additions are small individually, but together they make the tool much more useful for exploratory work.
